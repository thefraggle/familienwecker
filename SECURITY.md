# Security Policy

## Supported Versions

We release patches and security updates for the latest version of FamWake:

| Version | Supported          |
| ------- | ------------------ |
| 2.1.x   | :white_check_mark: |
| < 2.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within FamWake, please do **not** report it via a public GitHub issue.

Instead, please send an email directly to:
**famwake@goork.de**

Please include:
* A description of the vulnerability and its potential impact.
* Detailed steps to reproduce or a proof of concept.
* Any affected platforms (Android, iOS, Cloud Functions).

You will receive an acknowledgment within 48 hours. We appreciate your efforts to responsibly disclose vulnerabilities to protect our users.
